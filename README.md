# ✨ Studio Project – Frontend Web Experience

Welcome to the **Studio Project**, a dynamic, scroll-based frontend website built using modern web animation libraries like **GSAP** and **Locomotive Scroll**. This project demonstrates my skills in creating engaging, high-performance, visually immersive websites with advanced animations and smooth scrolling effects.

🔗 **Live Demo**: (https://studio-project-peach.vercel.app)  
📂 **GitHub Repo** : (https://github.com/Anjanisom0213/Studio-project)

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **GSAP (GreenSock Animation Platform)**
- **Locomotive Scroll**
- **Vercel** – for deployment

---

## 🎯 Features

- 💫 Smooth scroll animations using Locomotive Scroll
- 🎞 Advanced element transitions and animations with GSAP
- 🧭 Scroll-triggered content reveal and motion effects
- 📱 Responsive layout for mobile, tablet, and desktop
- ⚡ Fast loading and optimized performance
